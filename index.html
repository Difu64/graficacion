DEFINICIÓN PROPIA

La graficación por computadora es la forma de crear, transformar y mostrar imágenes mediante datos, algoritmos y dispositivos digitales para comunicar una idea o comprender información.

01 / LÍNEA DEL TIEMPO

Cinco momentos
que cambiaron la pantalla.

En cada etapa cambió una limitación: qué podía dibujarse, con qué precisión y para qué podía utilizarse.

1950—60

01 · PIONEROS

La pantalla como trazado

Limitación anterior: las computadoras tenían poca capacidad y las pantallas eran simples.

Cambio: los sistemas de visualización vectorial dibujaban líneas directamente.

Impacto: hicieron posible representar formas técnicas y datos geométricos.

Ejemplo actual: planos CAD y diagramas de líneas.

Fuente: Computer History Museum · historia de la computación.

1960—70

02 · PÍXELES

La imagen se vuelve una cuadrícula

Limitación anterior: las líneas no representaban bien texturas o imágenes fotográficas.

Cambio: la imagen rasterizada organiza la pantalla en píxeles, cada uno con un valor.

Impacto: se pudieron construir fotografías digitales, mapas de bits e interfaces detalladas.

Ejemplo actual: cámaras, teléfonos y pantallas de alta resolución.

Fuente: Encyclopaedia Britannica · Computer graphics.

1970—90

03 · 3D

De la figura al espacio

Limitación anterior: una imagen plana no expresaba volumen, profundidad ni perspectiva realista.

Cambio: los modelos tridimensionales describen objetos con vértices, superficies, luces y cámaras.

Impacto: la simulación y la animación pudieron representar espacios complejos.

Ejemplo actual: videojuegos, arquitectura y efectos visuales.

Fuente: Blender · About.

GPUCORE
1990—2000

04 · ACELERACIÓN

Más cálculos, en menos tiempo

Limitación anterior: dibujar escenas complejas podía ser demasiado lento para interactuar en tiempo real.

Cambio: las GPU procesan muchas operaciones gráficas en paralelo.

Impacto: aumentaron el detalle, la velocidad y la interactividad.

Ejemplo actual: videojuegos 3D, edición de video y visualización científica.

Fuente: NVIDIA · Historia y tecnología gráfica.

✳
HOY

05 · GRÁFICA EN TIEMPO REAL

La imagen responde al usuario

Limitación anterior: crear una visualización útil requería conocimientos técnicos y flujos de trabajo separados.

Cambio: motores en tiempo real, web y herramientas interactivas permiten explorar datos y escenas.

Impacto: las imágenes pueden actualizarse con cada decisión o dato nuevo.

Ejemplo actual: simuladores, mapas interactivos, configuradores y laboratorios web.

Fuente: MDN · Canvas API.

03 / LABORATORIO DE COLOR

Tres experimentos,
una misma luz.

Predice, cambia los valores y compara cómo describen un color los modelos RGB, CMY, HSV y HSL.

EXPERIMENTO 01

¿Qué pasa al mezclar canales?

Predicción: si aumento el verde y el azul sin cambiar el rojo, el color rojo se verá menos saturado.

RGB (128, 0, 0)
RGB (128, 64, 64)

Observación: el tono sigue cerca de 0°, pero la saturación baja de 100% a 50%.

Conclusión: el tono y la saturación describen propiedades distintas. Al acercarse los canales, disminuye la saturación.

EXPERIMENTO 02

RGB y CMY: luz frente a tinta

Predicción: mezclar luz RGB aumenta la luminosidad; mezclar tintas CMY absorbe más luz.

RGB
CMY

Datos: para RGB normalizado, el modelo CMY básico se calcula como C = 1 − R, M = 1 − G y Y = 1 − B.

Conclusión: RGB es aditivo y se usa en pantallas; CMY es sustractivo y sirve como base para impresión (que suele añadir K: CMYK).

EXPERIMENTO 03

HSV frente a HSL

Predicción: un mismo RGB puede tener valores V y L diferentes porque las fórmulas no son iguales.

HSL: H 210° · S 50% · L 50%
Referencia visual clara

Datos: RGB (64, 128, 192): máximo = 192/255 = 0.753; mínimo = 64/255 = 0.251; delta = 0.502.

Conclusión: HSV: H ≈ 210°, S ≈ 66.67%, V ≈ 75.29%. HSL: H ≈ 210°, S ≈ 50.39%, L ≈ 50.20%. El tono coincide, pero saturación y componente de claridad difieren.

04 / DEL COLOR AL CÓDIGO

Una fórmula
que toma decisiones.

La función recibe cualquier combinación RGB válida y devuelve solo { h, s, v }. H se expresa en grados; S y V, en porcentajes.

Pseudocódigo

Función convertRGBtoHSV(R, G, B)
  r ← R / 255; g ← G / 255; b ← B / 255
  maximo ← máximo(r, g, b)
  minimo ← mínimo(r, g, b)
  delta ← maximo - minimo
  h ← 0; s ← 0; v ← maximo × 100

  Si delta ≠ 0:
    s ← (delta / maximo) × 100
    Si maximo = r:
      h ← 60 × (((g - b) / delta) módulo 6)
    Sino si maximo = g:
      h ← 60 × ((b - r) / delta + 2)
    Sino:
      h ← 60 × ((r - g) / delta + 4)

  Si h < 0: h ← h + 360
  devolver { h, s, v }

Función JavaScript

function convertRGBtoHSV(R, G, B) {
  if (![R, G, B].every(Number.isFinite) ||
      [R, G, B].some(n => n < 0 || n > 255)) {
    throw new Error("RGB debe estar entre 0 y 255");
  }

  const r = R / 255, g = G / 255, b = B / 255;
  const maximo = Math.max(r, g, b);
  const minimo = Math.min(r, g, b);
  const delta = maximo - minimo;
  let h = 0, s = 0;
  const v = maximo * 100;

  if (delta !== 0) {
    s = (delta / maximo) * 100;
    if (maximo === r) h = 60 * (((g-b)/delta) % 6);
    else if (maximo === g) h = 60 * ((b-r)/delta + 2);
    else h = 60 * ((r-g)/delta + 4);
  }
  if (h < 0) h += 360;
  return {
    h: Number(h.toFixed(2)),
    s: Number(s.toFixed(2)),
    v: Number(v.toFixed(2))
  };
}

Prueba: RGB (64, 128, 192).

Δ

¿Por qué importa delta = 0?

Delta es la diferencia entre el canal mayor y el menor. Si delta = 0, los tres canales son iguales: el color es acromático (negro, gris o blanco). No hay diferencia cromática, por eso asignamos h = 0 y s = 0; además, evitamos dividir entre cero al calcular el tono.

05 / GLOSARIO

Diez palabras
para mirar mejor.

Definiciones prácticas, expresadas en lenguaje cotidiano.

01. Graficación

Crear o transformar imágenes con ayuda de una computadora.

Ejemplo: modelar una silla en 3D.

02. Píxel

Pequeño elemento de una imagen digital al que se asigna un color.

Ejemplo: cada punto de una fotografía.

03. RGB

Modelo que mezcla luz roja, verde y azul para formar colores.

Ejemplo: una pantalla LED.

04. CMY

Modelo sustractivo basado en cian, magenta y amarillo; absorbe partes de la luz.

Ejemplo: tintas de impresión.

05. HSV

Modelo que describe color por tono, saturación y valor.

Ejemplo: selector de color de una aplicación.

06. HSL

Modelo que usa tono, saturación y luminosidad.

Ejemplo: aclarar un color manteniendo el tono.

07. Tono (H)

La familia cromática que reconocemos, medida en grados alrededor de una rueda.

Ejemplo: rojo ≈ 0°.

08. Saturación (S)

Qué tan intenso o apagado se percibe un color.

Ejemplo: rojo puro frente a rosa grisáceo.

09. Valor (V)

En HSV, indica el nivel del canal más alto y va de negro hacia el color más brillante posible.

Ejemplo: RGB (128, 0, 0) tiene V ≈ 50.20%.

10. Delta (Δ)

Diferencia entre el canal RGB máximo y el mínimo después de normalizarlos.

Ejemplo: 0.753 − 0.251 = 0.502.

11. Normalización

Convertir los canales de una escala 0–255 a una escala 0–1.

Ejemplo: 128 / 255 ≈ 0.502.

12. Acromático

Color sin componente cromática: negro, gris o blanco.

Ejemplo: RGB (120, 120, 120).

06 / CIERRE

La evidencia
cambia la mirada.

Idea inicial

Al principio pensaba que el brillo y la intensidad dependían solamente del canal RGB más alto.

Evidencia

Al comparar RGB (128, 0, 0) con RGB (128, 64, 64), observé que el tono sigue en 0° y el valor en 50.20%, mientras la saturación baja de 100% a 50%.

Lo que aprendí

El máximo determina V en HSV, pero la diferencia entre máximo y mínimo permite calcular delta y afecta la saturación. El color se puede describir de varias maneras según la pregunta que queremos responder.
